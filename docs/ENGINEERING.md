# 工程规范（通用版）

> 状态：**已定题《昨晚的我有限公司》（2026-11-21）**。第 1–7 节是通用规则，第 8 节是本项目的机制清单。执行分工见 [WAKE_CONTRACT_PLAN.md](WAKE_CONTRACT_PLAN.md)。
> 依据：Devpost 赛道要求（Bad UX ≠ Bad Coding、至少一条完整路径、可见结果）与提交要求（可访问链接、公开仓库、Apache-2.0、AMD 海报）。

## 1. 抓狂必须是设计出来的

- 每个抓狂机制都写清楚四件事：**触发条件**、**上限**（最多折磨几次或多久）、**合法通关路径**、**背后的设计逻辑**。
- 禁止用真问题制造困难：页面报错、控制台报错、按钮无响应、流程卡死、数据丢失都算 Bug，不算机制。
- 流程用明确的状态来控制（当前在哪一步、能去哪一步），保证任何状态下都有路可走。
- 用户走错路或点错按钮时，只回退当前这一步，已完成的进度保留。

## 2. AI 必须有兜底

- 所有 AI 调用都要设超时（建议 8 秒以内）。
- 超时或失败时，自动切换到预设内容（预设题目、预设回复），界面上不报错，演示不卡住。
- API Key 只放在后端或本地 `.env`，前端代码里不出现密钥。
- 演示前准备一个「离线模式」开关：现场网络不好时，所有 AI 环节直接走预设内容。
- 摄像头类功能：画面只在浏览器本地处理，不上传、不保存；用户拒绝授权时必须有不用摄像头的替代路径。

## 3. 演示可以重复

- **一键重置**：清空本次数据，回到起点，下一位评委可以马上体验。
- **静音开关**：有声音的项目必须有，而且静音不影响流程。
- **演示数据预置**：需要较长时间输入的环节，预先准备好半成品，评委只需完成关键操作。
- 单次完整体验控制在 **2–3 分钟**，留出问答时间。

## 4. 可见结果来自真实数据

- 结果页里的耗时、次数、分析都来自本次实际操作，不写死。
- 结果页本身就是展示的一部分，要能截图放进海报和 Devpost 页面。

## 5. 好 UX 的底线

- 除了刻意设计的抓狂机制，其余部分都按好的标准做：字号清晰、对比度达标、键盘可操作、焦点可见、文案通顺。
- 刻意违反好 UX 的地方，在下方第 8 节逐条登记，写清违反的是哪条原则、为什么。评委问起时有依据，也方便做「查看设计逻辑」之类的功能。
- 尊重系统的「减少动态效果」设置：开启时，晃动、闪烁类动画要减弱或关闭。

## 6. 提交硬要求

- **可访问的 demo 链接**：网页版部署上线（Vercel、GitHub Pages 等），截止前用手机和别人的电脑各打开一次。
- **仓库公开 + Apache-2.0**：根目录保留 `LICENSE`。
- **披露**：README 和 Devpost 页面写明用到的开源库、第三方 API、AI 辅助开发工具。
- **海报**：用 AMD 生成，保留原始未编辑图像和 Creative Factory Gallery 截图。
- **密钥安全**：真实 Key 只放 `.env`，`.env.example` 只写变量名。

## 7. 时间与协作纪律

- 功能分层推进：每一层做稳了再做下一层，不同时开多个半成品。
- **11 月 22 日 11:00 功能冻结**，之后只修 Bug、打磨演示、写 README 和路演材料。
- Git 规则见 `AGENTS.md`：不直接推 `main`，各自在 `feat/<名字>-<主题>` 分支开发，经常合并 `origin/main`。
- 冻结前至少在演示电脑上从零拉取、安装、运行一遍。

## 8. 机制清单

每个机制一行，开发和路演共用这张表。改机制时同步改这里。

| 机制 | 触发条件 | 上限 | 合法通关路径 | 违反的 UX 原则 / 设计逻辑 | AI 兜底 |
| --- | --- | --- | --- | --- | --- |
| 关闭只登记意向 | 响铃时点「关闭闹钟」 | 一次提示 | 进入清醒认证 | 按钮标签应兑现预期；防止睡眠惯性下一键关掉 | 无 AI |
| 滑块提交算术答案 | 清醒认证阶段 | 答错留在本题，可无限重试 | 拖到正确值（方向键可微调） | 控件应匹配任务；精细操作本身检验清醒 | 无 AI |
| 认证后仍需验收 | 答题通过后 | 「继续监督」只回到验收说明 | 选择视觉次要但清晰可读的「完成验收并关闭」 | 完成后应能轻松离开；提高"关掉再睡"的成本 | 无 AI |
| 严格合同修订 | 严格合同贪睡，或宽松合同第二次贪睡 | 每次贪睡一次修订 | 把时间改为当前约定 + 5 分钟并确认 | 过去的授权约束现在的选择（承诺装置） | 无 AI |
| 个性化清醒认证（深化 1） | 关闭申请后 | 连续 3 次不达标仍放行，回执记"勉强清醒" | 中位反应时间 ≤ 基线 × 1.3 | 拿自己比自己；模拟睡眠惯性 | 无 AI |
| AI 甲方（深化 2） | 修订页写下借口 | 只显示文字，不阻拦 | 照常修订 | 让昨晚的意志开口 | 8 秒超时或失败时显示"你昨晚说：{理由}" |
| 动作签名（深化 4，21:00 决定） | 关闭申请后，签约时录过姿势 | 3 次未通过自动改走反应测试 | 复现昨晚的姿势，相似度达标 | 拿自己比自己；起身做动作本身提神 | 无 AI；没有摄像头或拒绝授权时改走反应测试 |
| 不可抗力 | 任一响铃阶段 | 随时可用 | 直接停响，回执如实记录 | 有分寸的严格，保证永远有出口 | 无 AI |
