## 三件套是什么

| # | 物品 | 去向 |
| --- | --- | --- |
| ① | **最终项目海报**（AMD 原图上轻度编辑：排版、加字、叠加真实截图） | Devpost **Project image** + 导出 **PDF** 上传 **File Upload** 字段（两处都要交） |
| ② | **AMD 未编辑原图**（Raw Image，一个字节都不能改） | 存入本目录 `pitch/poster/raw/`，取 GitHub 公开链接填入 Devpost 必答项 |
| ③ | **生成证明截图**（AMD Creative Factory → Image → My work → Gallery 页面截图） | 存入本目录 `pitch/poster/proof/`，取公开链接填入 Devpost 必答项 |

## 红线（违反即废）

- 主视觉必须出自 **AMD Creative Factory（OneclickAMD）→ Image**。**严禁**用其他生图工具（含通用 AI 绘图）重绘或替换核心视觉。
- 允许的编辑只有：调色、锐化、修瑕疵、裁剪、排版、加字、叠加真实界面截图。
- AMD API Key 只放本地 `.env` 和 Vercel 环境变量，**不进仓库**；`.env.example` 只写变量名。

## 海报内容要求（官方原文）

海报必须概括三件事：
1. **用户与任务场景**：早八大学生、闹钟响了顺手关掉又睡回去；
2. **核心功能 / 反向设计机制**：起床合同（甲方昨晚的你 / 乙方今早的你）、三处必做的抓狂机制（意向登记 / 滑块答题 / 二次验收）+ 修订手续；
3. **关键设计启示**：睡眠惯性 + 承诺装置——"当用户改变主意时，产品该听过去的他还是现在的他？"＋调研数据（__ 人 / __% / 一句原话）。

## 制作流程（明天上午，候选版本就绪后）

0. **获取工具（官方赞助资源，Key 严禁入库）**：
   - 海报主视觉工具：**Creative Factory（OneclickAMD）**，注册即送 **每人 100 积分**，入口 `https://h3.oneclickamd.ai/video`；安装指南在主办方发放的网盘链接（提取码见团队群，**不写入本仓库**——仓库是公开的）。
   - 其他赞助资源备用：AIHubMix / Tokener.ai（每队 US$12 额度，兑换码发给了队长，只放 `.env`）、Dify 免费版（这些主要供成员 3 的 AI 甲方使用，海报一般用不到）。
1. **生成主视觉**：用 OneclickAMD / Creative Factory → Image 生成主视觉（建议主题：清晨床铺与一份发光的合同 / 昨晚与今早两个自己握手）。
2. **立即归档**：未编辑原图存 `pitch/poster/raw/`；Gallery 页面截图存 `pitch/poster/proof/`。
3. **轻度编辑**：在原图上排版加字：标题、一句话定位、三处机制、调研数据、真实界面截图（履约报告页必截）。
4. **导出双份**：PNG 作 Devpost Project image；同版式导出 PDF 作 File Upload。
5. **链接核验**：推到 GitHub 后用无痕窗口确认 ② ③ 两个公开链接可访问。
