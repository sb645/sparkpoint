# 概念重定位：从「监考器」改成「公证处」

> 问题诊断：现有提案的三处机制（禁粘贴、删除配额、AI 抽查）摩擦服务于**学校**，产品身份变成监考器。
> Reverse UX 要的是"用户讨厌但不得不用"，不是"机构压迫用户"。区别在于：**摩擦服务谁。**
> 改法：产品不是防你作弊的工具，而是**你被冤枉时唯一能自证的工具**。摩擦不是惩罚，是**举证成本**。

## 一、重新定义产品身份

| | 旧版（监考器） | 新版（公证处） |
| --- | --- | --- |
| 谁是用户 | 学校（要抓作弊） | 学生（要自证清白） |
| 用户为什么用 | 被强制安装 | 被误判时，只有它能拿出证据 |
| 摩擦的性质 | 惩罚（不让你好过） | 举证成本（要证明，就得付手续费） |
| 用户走完流程得到 | 一个合规标记 | 一份可采信的人类撰写证书 |
| 谁决定数据去哪 | 学校 | 学生自己（可选择是否分享给老师） |

**一句话**：不是"学校监视你写作"，是"你花钱请了一个公证员，全程录像，最后给你盖章"。公证处烦不烦？烦。但你被冤枉的时候，只有它救你。

## 二、三个机制重排（每条都从"惩罚"改成"举证"）

### 机制 1｜粘贴的文字不算你的（原：禁止粘贴）
- **新规则**：允许粘贴，但粘进来的段落**不计入"人类撰写"部分**，证书上标为"引用/未验证"。要计入，必须在该段落里**用自己的话复写关键句**（系统保留复写记录）。
- **用户为什么抓狂**：我自己写的备忘录，粘过来居然不算数？
- **设计逻辑**：证书只认有"思考痕迹"的文字。这不是防你抄，是**公证员只对亲眼看见的过程负责**。违反的原则："系统应接受用户的合法输入"。

### 机制 2｜出证前必须看完自己的回放（替换：删除键配额）
- **新规则**：删除配额**砍掉**（它既不为证明服务，也解释不通，是最弱的一环）。改成：出证前必须**完整看一遍自己的打字回放**，关键标红段落不能跳过、不能加速。
- **用户为什么抓狂**：写了 40 分钟，还要坐着看 40 分钟自己打字的录像。
- **设计逻辑**：证书要你**背书**。你签的字，你得看过。违反的原则："完成任务后应能立刻离开"。
- **额外好处**：开发量比删除配额更小（回放本来就是深度 1 的必做项）。

### 机制 3｜标红段落要当场"答辩"（原：AI 抽查后重写）
- **新规则**：系统按打字痕迹标红可疑段落后，你要**逐段写下"当时为什么这么写"**。答得上来，该段转为"已解释"；答不上来，**该段不计入证书**（不是重写，是扣分）。
- **用户为什么抓狂**：写完了还要被审问，还要打字解释自己。
- **设计逻辑**：证书的可信度来自"你能解释自己的每一句话"。注意：**不重写**——重写是惩罚，扣分是举证失败，逻辑更干净。
- **演示高光升级**：评委照抄一段 → 速度曲线变平 → 标红 → 当场被要求解释 → 答不上来 → 这段从证书里消失。比"重写"更有戏剧性，也更公平。

## 三、这个产品的哲学内核（创意分的真正来源）

> **它把"举证责任倒置"做成了产品。**

正常情况下，指控你的人要证明你有罪。这个产品反过来：**被怀疑的人要自己付出额外劳动，证明自己没做错事。**

这就是它"逆向"的地方——不是三条烦人的交互，而是**一条更根本的原则被违反了：无罪推定**。用户讨厌它，是因为它默认你有嫌疑；用户不得不用它，是因为**不用就等于认罪**。

> 讲稿金句："这个产品最狠的地方，不是它让你写得难受，而是它让你**必须先被怀疑，才有资格被相信**。"

## 四、这对赛道四问的回答

| 赛道要求 | 回答 |
| --- | --- |
| 至少三处刻意抓狂 | 粘贴不算数 / 出证前看完回放 / 标红段落答辩 |
| Bad UX ≠ Bad Coding | 只有这三处难用；编辑器本身字号、对比度、快捷键、撤销全部按好标准做 |
| 至少一条路走通 | 正常写作 → 看回放 → 答辩 → 出证，全程可完成；答不上来只是该段不计入，不阻断出证 |
| 阐释设计逻辑 | 每一处摩擦都是"证据链"的必要环节；总逻辑是举证责任倒置 |

## 五、"不得不"的来源（比赛要求的第二根支柱）

- **被误判时**：AI 检测器说你作弊，你的完整打字记录 + 答辩记录是唯一拿得出手的证据；
- **学校要求提交时**：作业必须附证书——但这句话要在路演里**轻描淡写地提一句**，重点永远是"学生自证"，不是"学校监控"。

## 六、必须提前想好的两个追问

1. **"这不就是监控学生吗？"**
   > "反过来：数据在你自己手里，你决定什么时候、给谁看。它是你被冤枉时的证据，不是老师随时能翻的台账。老师端只有你分享的那一份。"
2. **"Grammarly Authorship / GPTZero 不是已经有了吗？"**
   > "它们做的是'判断文字像不像 AI'，我们做的是'判断过程像不像人在思考'，并且把它变成一份**你能拿去自证的证书**。检测器给你一个分数，我们给你一份证据。"

## 七、对开发的影响（比旧提案更省）

| 变化 | 影响 |
| --- | --- |
| 砍掉删除配额 | **少一个计数器和一套配额 UI** |
| 答辩替代"重写" | 少一套"重置段落"逻辑，多一个文本框 + 状态标记 |
| 回放看完作为出证门槛 | 深度 1 本来就要做，只加一个"已看完"标记 |
| 粘贴段落进"待复写区" | 粘贴拦截逻辑改成"分区标记"，比硬拦截简单 |
