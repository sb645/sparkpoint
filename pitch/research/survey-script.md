# 现场调研脚本与记录模板（成员 4 · 17:30 前回传数据）

> 目标：累计 10–20 位同学的快速调研。产出三样东西：**实际人数与关键比例**、**至少一句匿名原话**、**一处因此调整的设计**。
> 结论将写入海报、README 和 Devpost 描述（对应评分项"用户需求与问题理解"20%）。
> 本文件分两部分：A. 线上问卷题（即刻发到群里）；B. 现场快访脚本（3–5 位同学深度一点）。

## A. 线上问卷题（发到年级群 / 班级群，匿名）

导语：我们在做一个关于"早起"的课程作品调研，共 5 题，1 分钟完成，完全匿名。

1. 你有早八或必须早起的安排吗？（有 / 没有）
2. 这学期，你关掉闹钟之后又睡回去过吗？（经常 / 偶尔 / 从不）
3. 最严重的一次，后果是什么？（迟到 / 翘课 / 被点名 / 错过约定 / 没有后果 / 其他）
4. 闹钟响的那一刻，你心里通常怎么想？（一句话，选最接近的：再睡五分钟肯定来得及 / 反正迟到也无所谓 / 我知道该起但身体不动 / 其他）
5. 如果有一种办法能让"昨晚下定决心要早起的我"管住"今早起不来的我"，你愿意试试吗？（愿意 / 不愿意 / 看情况）

## B. 现场快访脚本（每人约 2 分钟，目标 3–5 人）

开场白（原样照读）：
> "打扰一下，我们在做一个作品：一个由'昨晚的你'定规则、'今早的你'必须照做的闹钟。想问你几个关于早起的问题，匿名，两分钟。"

问题（按顺序，不打断，原话逐字记录）：

1. 你今早是怎么醒的？闹钟响了几次？
2. 这学期有没有闹钟响了、你顺手关掉、然后又睡回去的经历？当时是什么情况？
3. 那个瞬间，你心里怎么想的？（等对方说出原话，逐字记）
4. 为此付出过什么代价？（迟到、翘课、错过接人 / 赶车之类）
5. 如果能重来一次，你希望那一刻有谁拦着你？

收尾（原样照读）：
> "最后一个问题：如果一个 App 要求你必须按昨晚自己签的'起床合同'执行，你觉得它是帮你还是折磨你？"
